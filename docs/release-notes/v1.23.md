# v1.23 Release Notes

Release covering changes since [v1.22.0](https://github.com/MaslowCNC/Maslow_4/releases/tag/v1.22.0).

[Full changelog: compare v1.22.0 to v1.23](https://github.com/MaslowCNC/Maslow_4/compare/v1.22.0...v1.23)

---

## Highlights

- **Fixed automatic firmware update (OTA)**: The over-the-air update dialog now downloads release assets from a GitHub-mirrored path (`web-assets/<tag>/`) on `raw.githubusercontent.com`, which serves correct CORS headers. This replaces the previous approach that used direct GitHub release asset URLs, which caused cross-origin failures in the browser and required the ESP32 to perform HTTPS downloads it lacked the RAM to complete.
- **Fixed Z home reset on startup**: When the stored Z home value is outside the valid range (0–72 mm) at startup, the firmware now actually resets Z home to the current machine position (Zm) rather than only logging a warning and leaving the out-of-range value in place.

---

## Firmware changes

- **Fix: Reset Z home to Zm on startup when out of range** ([#1027](https://github.com/MaslowCNC/Maslow_4/pull/1027), `1c37712`)
  - `loadZPos()` now executes `G92.1` followed by `G10 L20 P0 Z0` when a startup Z home value outside 0–72 mm is detected, setting work Z = 0 at the current machine position.
  - Previously only a warning was logged and the out-of-range value was kept, which could leave the machine in a confused state.

---

## UI / Web changes

- **Fixed OTA update system** ([#1025](https://github.com/MaslowCNC/Maslow_4/pull/1025), `e006562`)
  - Release assets (firmware.bin, index.html.gz) are now fetched from the mirrored `web-assets/` directory in the repository instead of directly from the GitHub Releases API.
  - `raw.githubusercontent.com` provides `Access-Control-Allow-Origin: *`, allowing the browser to download the blobs and upload them to the device over the existing upload endpoints.
  - A streaming downloader with progress reporting is included so large firmware files show accurate progress.
  - The update dialog falls back from the version-specific mirror path to `web-assets/latest/` if the versioned path is unavailable.

---

## Fixes

- Z home out-of-range condition on startup no longer silently persists ([#1027](https://github.com/MaslowCNC/Maslow_4/pull/1027))
- OTA update failures caused by missing CORS headers on GitHub release asset URLs are resolved ([#1025](https://github.com/MaslowCNC/Maslow_4/pull/1025))
