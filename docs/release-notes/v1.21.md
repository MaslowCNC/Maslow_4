# Maslow Version 1.21 Release Notes

Version 1.21 brings a new Park button, a redesigned Optional Settings menu, Z-axis safety improvements, and fixes for several reliability issues. No changes to your maslow.yaml file are required to use these features, though Park position can be customized in Optional Settings.

## Park Button

**The machine can now automatically park itself when you're done cutting.** When the machine is in the Ready to Cut state and idle, a green "Park" button appears. Clicking it raises the Z axis to a safe height first — lifting the bit clear of your workpiece — then moves the machine to a configurable park position (default: machine coordinate origin X=0, Y=0). You can customize the park X, Y, and Z coordinates in Optional Settings or directly in maslow.yaml.

## Optional Settings Menu

**A new "Options" button on the main UI organizes machine configuration into one place.** Clicking Options opens a popup with three configuration dialogs:

- **Set Work Area** — enter the dimensions and offset of your work surface
- **Set Park** — configure the X, Y, and Z coordinates the machine moves to when Park is pressed
- **Set Scale and Thickness** — set Scale X, Scale Y, Work Thickness, and Spoilboard Thickness

## Find Anchors Improvements

**A safety confirmation is now required before Find Anchors starts.** When you click Find Anchors, a dialog asks you to confirm that the Z axis is fully lowered before proceeding. Running Find Anchors with Z raised can cause incorrect results or damage to the frame.

**The interface now focuses on what matters during Find Anchors.** While Find Anchors is running, the position display, file controls, and playback controls are automatically hidden, and the serial messages area expands so you can follow the progress output more easily. Everything returns to normal when the process completes.

**Firmware status messages now consistently say "Find Anchors."** All firmware log messages that previously said "calibration" now say "Find Anchors," matching the terminology used throughout the rest of the interface.

## Z-Axis Safety

**A warning popup now appears when the Z axis may be in an unsafe position.** If the Z axis is higher than 72mm above home when the interface loads, or if a movement would push it beyond the safe range, a popup warns you before anything moves. This prevents accidentally plunging the bit into your workpiece after homing with the bit raised too high.

## Bug Fixes

**Fixed Error 9 (SystemGcLock) when jogging rapidly.** Sending multiple jog commands in quick succession could produce Error 9 because the firmware rejected a standalone G20/G21 units command that arrived while the machine was already jogging. The units are now embedded directly in the jog command, which the firmware permits during jogging.

**Run button is now disabled until the machine is Ready to Cut.** Previously the Run button appeared active even before the machine had completed its startup sequence. The button is now grayed out until Maslow reports Ready to Cut state.

**Fixed the red LED alarm being triggered during firmware and file uploads.** Two related bugs caused the watchdog to fire incorrectly during uploads, latching the red LED on and requiring a power cycle to clear it. The watchdog is now properly suppressed while uploads are in progress.

**Fixed browser spinning at 100% CPU when the network disconnects.** When the WiFi connection dropped, the disconnect dialog triggered an infinite command-processing loop that pinned the browser at 100% CPU. This loop has been eliminated, and the browser now automatically attempts to reconnect every 3 seconds instead of requiring a manual page reload.

**WiFi networks with spaces or commas in their name now work.** The SSID input field was rejecting these characters even though the firmware already accepted them. The input validation has been updated to match what the firmware actually supports.
