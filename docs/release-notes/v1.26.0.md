# v1.26.0 Firmware Release

Version 1.26.0 improves loaded-job work-area feedback, streamlines tablet
controls, and makes it easier to retain serial diagnostics after a fault.

## Highlights

- Checks a loaded G-code job against the configured XY work area after its
  preview loads and when XY home is changed. Out-of-bounds placements show a
  warning with the job and work-area limits ([#1107](https://github.com/MaslowCNC/Maslow_4/pull/1107)).
- Moves Trace Boundary alongside the job bounds and adds a main-screen
  Release Tension control. Job-boundary controls are shown only when a job is
  loaded ([#1099](https://github.com/MaslowCNC/Maslow_4/pull/1099)).
- Automatically saves the serial log on the first alarm or fault report for
  an alarm state, helping preserve diagnostic details ([#1103](https://github.com/MaslowCNC/Maslow_4/pull/1103)).

## User interface improvements

- Hides native number-input arrows in tablet popups for a cleaner interface
  ([#1095](https://github.com/MaslowCNC/Maslow_4/pull/1095)).

## Upgrade notes

No `maslow.yaml` changes are required. If the UI warns that a loaded job is
outside the configured work area, verify the job placement and XY home before
cutting. The warning does not prevent an XY home change.
