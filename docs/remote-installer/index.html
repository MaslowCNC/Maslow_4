Maslow Remote Installer

Install the ESP-NOW remote firmware on the 4.0" ESP32-S3 touch display straight from this page. Nothing to download or install.

This browser can't talk to USB serial ports. Open this page in Chrome or Edge on a computer, or use a Full-Install package instead.

1. Plug in the display

Plug the display into the computer with a USB-C data cable (some cables only charge).

2. Click Install

A window lists the serial ports: pick the display's port and click Connect. Choose Erase when asked; it takes about a minute.

4.0" ESP32-S3 touch display

Hosyond / lcdwiki ES3C40P: 320×480 IPS, capacitive touch, USB-C

Needs https

3. Pair

The remote restarts by itself. Turn the Maslow off and on again, and within 2 minutes tap Pair on the remote.

If the port doesn't show up

  • Try another USB cable or port, and close any other program that has the port open.
  • Hold the board's BOOT button while plugging it in, then click Install again.

Prefer a program?

Download the package for your computer, unpack the whole zip and run Full-Install. Each package carries everything it needs.

  • Windows: double-click Full-Install.bat
  • macOS: double-click Full-Install.command
  • Linux: run sh Full-Install.sh
