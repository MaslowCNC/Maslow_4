Maslow CNC Calibration Simulator

About this simulation: This tool simulates the exact calibration process used by the Maslow CNC machine. It mimics how the machine collects measurements at calibration waypoints and sends them in chunks to the browser for computation. Unlike the previous simulation, this one accurately models the multi-stage computation process where anchor positions are recomputed multiple times as more measurements are collected.
