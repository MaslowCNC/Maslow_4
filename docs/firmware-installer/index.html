Maslow Firmware Installer

Install the Maslow firmware and web interface on the Maslow's control board over USB, straight from this page.

Looking up the latest release…

This browser can't talk to USB serial ports. Open this page in Chrome or Edge on a computer, or use the install scripts in the release zip.

1. Plug in the control board

Stop any job and release belt tension first: the board restarts during the install. Then connect the control board's USB-C port to the computer with a data cable (some cables only charge).

2. Choose what to install

3. Install

Click Install, pick the board's port and click Connect. It takes about two minutes; keep this tab open and in front until it finishes.

    Details 
    
    
    
  
    

  
    If the port doesn't show up or the install fails
    
  
      
    
    • If it can't connect to the board: unplug the board's USB cable and its power supply, plug only the USB cable back in, and click Install straight away.
      • 
    
    • Close anything else using the board's port (another browser tab, a serial monitor, Arduino or PlatformIO).
      • 
    
    • Try another USB cable or port.
      • 
    
    • An update that failed part way can be run again. If the board no longer starts, run a clean install.
      • 
  
    
  
    Before changing anything, the page reads the files on the board and keeps a copy of maslow.yaml and any other files you added. A clean install saves that copy as a download, so you can put your settings back afterwards from the web interface.
