Maslow UI layouts

The chosen desktop layout for the WebUI rewrite (layout 6, numbered as in the original sketches) and three phone layouts, filled with sample content for each device state. During setup, the setup guide runs along the top, and the Device state panel, with Run and Stop pinned to its header, sits where Device config used to be. Outside setup, the top bar shows the device state with Run and Stop, and that panel shows the details. Values are examples, not readings from a device. The ⚙ button opens Settings. To click through a flow the way the device would run it, pick a Walkthrough: the buttons on the device screen then move it to the next state, and moving steps finish on their own.
