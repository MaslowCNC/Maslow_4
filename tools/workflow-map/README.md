# Workflow map

Maps of the machine workflow for the WebUI rewrite.

| File | What it is |
|---|---|
| `gen_ui_modes.py`, `template_ui_modes.html` | The UI modes version, which follows `ESP3D-WEBUI/REWRITE.md`. |
| `workflow-map-ui-modes.html` | The generated page. |
| `original/` | The first map's source, copied here from a temporary folder. |

To rebuild:

    python3 gen_ui_modes.py template_ui_modes.html workflow-map-ui-modes.html
