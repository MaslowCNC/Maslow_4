Monolith Maslow Rebuild (Stiffened, gantry style replacements for towers combined with Turtle Clamps)

## Compatibility

Maslow 4.0 / 4.1


## Description

A gantry style rebuild of the Maslow's towers, combined with the Turtle Clamps, for increased stiffness throughout.
2 * 350mm 2040 aluminium profiles are used for the towers, with 3D printed brackets to attache to the sled, and 3d printed rod holders used for securing the tops of the linear bearing rods. A crossbrace locks it all in place.

## Variants

* The cross-brace can be done with 2040 profile and the printed brackets, but a single 2020 profile and alu bracket are sufficient and save uneccessary weight.
* The linear bearing rods can either be the original, or can be replaced with 300mm rods for better travel.
* There are three sizes of the RodHolderRodClamp - 10.1mm, 10.25mm and 10.5mm. This is to account for printer variations. If the printer is true to size, 10.25mm should be right - and should slide onto the rod with no minimal resistance but no wobble. There are sizes up and down in case it prints loose/tight on your printer.
