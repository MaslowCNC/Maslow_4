## Installing Maslow 4 firmware over USB (macOS and Linux)

These scripts install the firmware on a Maslow 4 / 4.1 / Mini control board (ESP32-S3)
over a USB-C cable. To update a machine that is already running Maslow firmware, the
web UI's firmware update over WiFi is easier and keeps everything on the machine.

Chrome or Edge can do the same without these scripts: open
https://documentation.maslowcnc.com/firmware-installer/ and choose to keep
maslow.yaml or to erase everything.

You need Python 3. The first run creates a Python environment in ~/.fluidnc_venv and
installs esptool into it, which can take a few minutes.

Unzip this file, plug the board into USB, open a terminal in this folder and run one of:

  sh full-install.sh       Fresh install: erases the board, then installs the
                           filesystem and the firmware. Use this for a new board.
                           It deletes maslow.yaml, calibration and saved settings.
  sh install-wifi_s3.sh    Firmware only. Keeps maslow.yaml and your files.
  sh install-fs.sh         Filesystem only (web UI and config templates).
                           Deletes maslow.yaml and any files you uploaded.
  sh erase.sh              Erase everything on the board.
  sh fluidterm.sh          Serial terminal for talking to the board.

On macOS you can also double-click full-install.command.

After a fresh install the board starts with the config template for its board type.
Calibrate it (or upload your saved maslow.yaml) before cutting.

### Serial port permission problems (Linux)

If you see "Permission denied", add yourself to the dialout group, then log out and in:

    sudo usermod -aG dialout $USER

### Starting over

To rebuild the Python environment from scratch, delete it and run a script again:

    rm -rf ~/.fluidnc_venv
